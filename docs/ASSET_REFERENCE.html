Dream Xtreme Asset Reference

Every image the game needs, drawn to scale with its exact pixel size. Draw at the draw at size. The game scales it down and keeps the pixels sharp. White ink on black, 1-bit pixel art, hard edges. Color tints and the retro effects are added in code, so draw flat.

1. THE SCREEN390 × 844 px, a portrait phone. Draw at 2×: 780 × 1688 for a full screen.
2. THE LOOKWhite on black. 1-bit and dither. No gray gradients, no glows, no antialiasing on pixel art.
3. DROP INPut the file at the listed path. It replaces the placeholder automatically. Never rename.
4. FRAMESAnimated art is numbered frames, all the same size: name_0000.webp, name_0001.webp…
