# --- RICK-BARLOT ---

[rick-barlot / INTRO / Guns]

[rick-barlot / INTRO / Bible]
Gravel lot. Somebody has been coming here on the same night every week for years.

[rick-barlot / INTRO / Crystals]
Gravel lot. The bass through the wall arrives in your chest before your ears.

[rick-barlot / BARLOT_BIKE / Guns]
Parked across two spaces. That is the whole message, and it is meant for you.

[rick-barlot / BARLOT_BIKE / Bible]

[rick-barlot / BARLOT_BIKE / Crystals]
The chrome holds the door light and bends it into something almost soft.

[rick-barlot / BARLOT_ASHTRAY / Guns]
One brand, all of them. Same man, same spot, every night, waiting on something.

[rick-barlot / BARLOT_ASHTRAY / Bible]

[rick-barlot / BARLOT_ASHTRAY / Crystals]
Every one of them stubbed out the same careful way. Like a count of something.

[rick-barlot / BARLOT_FLYER / Guns]
A benefit ride. For a guy nobody in there will say the name of anymore.

[rick-barlot / BARLOT_FLYER / Bible]
A benefit ride, taped up crooked. They raised the money. That happened.

[rick-barlot / BARLOT_FLYER / Crystals]

[rick-barlot / QUICK BEAT — max 30 characters, no class variants]

# --- RWANDA-ALLEY ---

[rwanda-alley / INTRO / Bible]

[rwanda-alley / INTRO / Crystals]

[rwanda-alley / ALLEY_NEON / Bible]

[rwanda-alley / ALLEY_NEON / Crystals]

[rwanda-alley / ALLEY_PAYPHONE / Bible]

[rwanda-alley / ALLEY_PAYPHONE / Crystals]

[rwanda-alley / ALLEY_MURAL / Bible]

[rwanda-alley / ALLEY_MURAL / Crystals]
